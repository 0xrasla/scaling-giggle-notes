# The Ceiling Is Still You

A three-hour hands-on workshop on building software with AI agents - and on staying the person who can tell when it's wrong.

## What's inside

- `presentation/` - the full deck, keyboard-driven with speaker notes, live timers, and a progress ring
- `examples/` - working example projects used during the talk

## Run it

Open `presentation/index.html` in a browser. Arrow keys navigate, `N` toggles speaker notes.
